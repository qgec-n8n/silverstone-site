# Image Asset Rules

- Use this guidance only for image, asset, route redesign, image-composition, image-performance, or image-accessibility work.
- Before adding or replacing route imagery, inspect the actual candidate files and consult `docs/codex/image-assets/page-image-selection-policy.md` plus the verified manifests.
- Preserve licensing, source, desktop/mobile pairing, accessibility, dimensions/aspect-ratio, and route-behavior records.
- Do not omit images for implementation convenience or add images without a clear design function.
