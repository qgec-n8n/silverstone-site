# Silverstone AI Image Asset Catalogue for Codex

> Repository: `qgec-n8n/silverstone-site`  
> Coverage: **85 records** — 37 desktop, 35 responsive/mobile, 13 email extras.  
> Purpose: allow Codex to find, understand and select existing imagery for a premium, futuristic Vite website.

## How Codex should use this catalogue

1. Use **Repository path** first. If the repository has been reorganised, search using **Prefix search** and accept `.jpg`, `.jpeg`, `.png`, `.webp` or `.avif` matches.
2. Pair desktop and mobile records with `<picture>`/responsive sources. Mobile files are purpose-built square or portrait compositions, not simple crops.
3. Treat all UI, customer names, addresses, calendar entries and metrics inside the artwork as illustrative mock content.
4. Do not place important live copy over baked-in image copy. Use these as self-contained panels, section illustrations, or wide visual breaks.
5. For the new high-tech dark design, prioritise fit scores **9–10**; use bright/pastel assets deliberately as contrast sections.

## Dimension conventions

- Desktop CSV derivatives: `960 × 644` or `640 × 429`, approximately 3:2.
- Four homepage service mobile derivatives: `640 × 640`, 1:1.
- Other CSV mobile derivatives: `768 × 1145`, approximately 2:3 portrait.
- Email campaign set: `1264 × 848`, approximately 3:2, except the high-resolution booking/physio set at `2528 × 1696`.
