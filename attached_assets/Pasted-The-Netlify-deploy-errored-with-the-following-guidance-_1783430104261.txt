The Netlify deploy errored, with the following guidance provided:

**Diagnosis**  
- The build fails during `npm --prefix web ci` because NPM is trying to download packages from `http://package-firewall.replit.local`, which is inaccessible inside Netlify’s build environment. See the ENOTFOUND error at [line 57](#L57).

**Solution**  
- Remove or update any `.npmrc` or environment variable that forces the registry to `package-firewall.replit.local`.  
- Ensure the build uses the public registry instead. For example, delete the custom registry entry or run this before the install step:

```bash
npm config set registry https://registry.npmjs.org/
```

After the registry points to the public endpoint, re-trigger the Netlify build.
